## 2. 문제 정의와 프로젝트 기획

### 2-1. 문제 한 문장 (팀 확정: A안, 2026-11-26)
> **[현장 대리인·작업반장]이 [소규모 공공 설비공사 현장의 작업 전 안전점검]에서 겪는 [작업별 점검항목과 근거를 여러 권의 PDF·HWP 점검표에서 찾아야 하는 불편]을 [작업 유형별 체크리스트 Q&A 챗봇(출처 표시)]으로 줄이는 웹앱**

### 2-2. 문제의 근거 종류
| 근거 | 상태 |
|---|---|
| 자료 | 있음: 기업 공개정보(F1~F10), 고용노동부·안전보건공단 점검표, 2025 사망사고 통계 |
| 관찰 | 없음 (현장 방문 전) |
| 인터뷰 | 없음 (1-5 질문으로 진행 예정) |

→ 현재 문제는 **자료 기반 가설** 단계. 인터뷰 후 H1~H4를 사실/기각으로 갱신.

### 2-3. 핵심 기능 (처음엔 2개만)
1. **체크리스트 Q&A**: 작업 유형을 고르거나 질문을 입력하면, 등록된 점검표 안에서만 찾아 점검항목과 근거(문서명·쪽·조항)를 답함. 자료에 없으면 "자료에 없음, 안전관리자 확인 필요"라고 답함.
2. **작업 전 점검표 체크**: 답변에 나온 항목을 체크박스(적정/부적정/해당없음)로 바로 체크하고 결과를 화면에 요약.

나중에 할 것(이번 범위 아님): 사진 첨부, 점검 기록 저장·취합, 음성 입력.

### 2-4. 입력 화면
- 상단: 현장명, 날짜 (**[샘플 데이터]** 예: "샘플 현장 A - 학교 소방공사")
- 작업 유형 버튼: 용접·화기 / 밀폐공간 / 고소·사다리·지붕(태양광) / 전기 / 굴착·천공(지열)
- 질문 입력창: 예) "지붕 위 태양광 패널 작업 전에 뭘 확인해야 해?"
- 전송 버튼

### 2-5. 결과 화면
- 답변 카드: 점검항목 3~7개를 짧은 문장으로
- 각 항목 옆 출처 배지: 문서명 + 쪽/조항 (예: 안전보건규칙 제42조) + 원문 링크
- 항목별 체크박스: 적정 / 부적정 / 해당없음
- 하단 요약: "부적정 N개, 조치 필요 항목" + 안내문 "이 답변은 참고용이며 최종 판단은 현장 안전관리자가 합니다"
- 근거 자료에 없는 질문이면 답을 지어내지 않고 "확인 필요" 표시
